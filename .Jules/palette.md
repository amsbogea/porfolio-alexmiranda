## 2026-03-31 - Keyboard Accessibility & Navigation
**Learning:** Fixed header navigation overlays can obscure key landing content when navigating via keyboard or screen readers unless an explicit skip link and visible focus outlines are provided.
**Action:** Always include a `skip-to-content` link pointing directly to the primary `<main>` or hero section ID (`#apresentacao`), and set explicit `:focus-visible` outline styles using high-contrast design system tokens.
